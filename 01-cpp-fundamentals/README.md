# C++ Fundamentals

This folder contains short exercises from the early stage of the C++ journey.
The files are intentionally preserved in their original form.

## What the exercises practice

- Basic input and output
- Variables and arithmetic
- `if` and `switch`
- `while` and `do-while` loops
- Character and string processing
- Random number generation
- Small function-based programs

## How they work

Most programs follow a direct console flow:

```text
Read input -> process a condition or calculation -> print the result
```

These are exercises rather than one finished application. Their value is in
showing the transition from syntax practice to reusable program logic.
