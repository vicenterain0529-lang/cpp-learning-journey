# Library Management System

This project is a small library management system that I built to learn more about Python classes and basic program structure. It is still a beginner project, but it helped me practice organizing related features into separate modules.

## Features

- Manage books
- Manage borrowers
- Create book IDs with prefixes
- Organize the project into model-based folders

## Technologies used

- Python
- Object-oriented programming
- Console-based interface

## How to run

1. Open the project folder.
2. Run the main script:

```bash
python main.py
```

## Project structure

```text
main.py
models/
ui/
utils/
data/
```

## What I learned

I learned how to:

- think about how data should be structured in a simple system
