# Programming Inventory

This inventory was created from the files found under
`Documents\ALL PROGRAMMING RELATED` on September 5, 2026. Generated folders
(`.venv`, `__pycache__`, `.pio`, build directories, editor metadata, and
compiled output) were excluded.

## C++

- `1practiceC+++`: short fundamentals and syntax exercises.
- `prolog`: console exercises, OOP examples, Tic-Tac-Toe, scholarship versions,
  and an early enrollment program.
- `FINISHED PROJECTS/SCHOLARSHIP`: a multi-file `StudentApplication` project.
- `YTMP3DOWNLOADER/student enrollment`: a multi-file `Student`, `Course`, and
  `RegistrationSystem` project.
- `terminalGames C++`: Rock, Paper, Scissors and the Maze Chase game with
  `map.txt`.

## SDL3

`SDL 3 PROJECTS/FIRST SDL3` contains four prototype files using SDL3
initialization, windows, events, keyboard input, and position state. The code
does not yet demonstrate a complete renderer or finished game.

## Python

- `PYTHON1`: small console exercises and three versions of the creature battle
  project.
- `PYTHON1/to do list`: console and Tkinter task-list versions with JSON
  persistence.
- `PYTHON1/upload_repos`: guessing game, RPG simulator, and shopping cart.
- `PYTHON2`: banking, encryption, dice, and other exercises.
- `PYTHON2/Library_management`: a modular library application.
- `PYTHON2/student_management`: a modular student application with JSON
  persistence.
- `YTMP3DOWNLOADER/ytdown.py`: a downloader experiment.

## Arduino / PlatformIO

`PlatformIO/Projects/ledtest` and `letdtest` contain Arduino C++ `main.cpp`
files and PlatformIO configuration for LED experiments. Build directories and
generated PlatformIO files were not copied.

## Upload Decisions

Source files and meaningful project documentation were preserved. Generated
virtual environments, Python caches, PlatformIO `.pio` directories, compiled
outputs from the Documents scan, and editor-only configuration were excluded.
The repository's existing published Maze Chase executable remains because it
was already an intentional release artifact. A generated
`student_master_list.json` was also excluded because it contained a real
student ID and personal record; the student-management source remains included.
