# Rock, Paper, Scissors

## Overview

A console game that compares the player's choice with a random enemy choice
and tracks both scores.

## How it works

```text
Ask whether to play -> read move -> generate enemy move
        -> compare choices -> update and display score
```

The program uses functions for random selection, displaying choices, checking
the winner, and printing scores. A fourth menu option exits the round.

## Concepts demonstrated

- Input validation
- `switch` and conditional logic
- Loops and repeated rounds
- Function prototypes
- Random number generation
- Reference parameters for score updates

## Current status

**Completed exercise.** It is an early console project and is preserved as a
record of the first game-oriented C++ work.
