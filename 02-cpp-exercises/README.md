# C++ Exercises and OOP Practice

This folder groups console exercises from the `prolog` collection, including
OOP examples, a quiz, Tic-Tac-Toe, scholarship iterations, and an early
enrollment experiment.

## Concepts demonstrated

- Classes, objects, constructors, and private/public members
- Inheritance through `Warrior : public Human`
- Arrays and `struct Student`
- `std::vector`
- Input validation and console menus
- Game and quiz control flow

## Status

These files are **Exercises** and **Experiments**. They represent intermediate
practice and earlier versions; they are not presented as one unified product.
